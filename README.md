# Cloud-task-manager
A simple and user-friendly **Cloud Task Manager** built using **Node.js, Express.js, MongoDB Atlas, HTML, CSS, and JavaScript**.

This project allows users to create, manage, update, and delete tasks while storing task data in a MongoDB database.

## 🚀 Features

- ➕ Add new tasks
- 📝 Add task descriptions
- 🎯 Set task priority
- 🔄 Update task status
- 🗑️ Delete tasks
- 🔍 Filter tasks
- 📊 Dashboard with task statistics
- 💾 Persistent data storage using MongoDB Atlas
- 🌐 REST API using Express.js
- 📱 Simple and responsive user interface

## 🛠️ Technologies Used

### Frontend
- HTML5
- CSS3
- JavaScript

### Backend
- Node.js
- Express.js

### Database
- MongoDB Atlas

### Deployment
- GitHub
- Node.js hosting platform
